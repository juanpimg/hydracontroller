How it works

Three simple pieces, all on your local network.

  1. 1 · Install the serverOne command on your Linux PC. It generates its own TLS certificate and shows you a QR code.
  2. 2 · Scan and tapOpen the web app on your phone, pick an app, and it launches on its own virtual display.
  3. 3 · Watch and controlVideo arrives over WebSocket and your fingers come back as mouse and keyboard events.
Phone (PWA) ──HTTPS/WSS :4096──▶ Node server
                                        ├─ headless gamescope (isolated display :N)
                                        ├─ GStreamer + PipeWire ──▶ MJPEG ──▶ phone
                                        └─ your fingers ──▶ xdotool ──▶ app

Install it today

Linux with gamescope and Node.js. Five minutes.

sudo pacman -S gcc make ffmpeg gamescope nodejs npm   # or apt/dnf equivalents
sudo usermod -aG input $USER   # permission for /dev/uinput (optional)
npm install && npm run build
npm start   # scan the QR with your phone (same Wi-Fi)

Full step-by-step guide, local development, and troubleshooting in the repository README.

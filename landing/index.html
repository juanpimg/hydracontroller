Cómo funciona

Tres piezas simples, todo en tu red local.

  1. 1 · Instala el servidorUn comando en tu PC Linux. Genera su propio certificado TLS y te muestra un QR.
  2. 2 · Escanea y tocaAbres la web en el móvil, eliges una app y se lanza en un display virtual propio.
  3. 3 · Mírala y contrólalaEl vídeo llega por WebSocket y tus dedos vuelven como eventos de ratón y teclado.
Móvil (PWA) ──HTTPS/WSS :4096──▶ Servidor Node
                                        ├─ gamescope headless (display :N aislado)
                                        ├─ GStreamer + PipeWire ──▶ MJPEG ──▶ móvil
                                        └─ tus dedos ──▶ xdotool ──▶ app

Instálalo hoy

Linux con gamescope y Node.js. Cinco minutos.

sudo pacman -S gcc make ffmpeg gamescope nodejs npm   # o apt/dnf equivalentes
sudo usermod -aG input $USER   # permiso para /dev/uinput (opcional)
npm install && npm run build
npm start   # escanea el QR con el móvil (misma Wi-Fi)

Guía completa paso a paso, desarrollo local y solución de problemas en el README del repositorio.
